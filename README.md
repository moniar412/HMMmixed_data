Title: COMPOSITE LIKELIHOOD INFERENCE FOR SIMULTANEOUS CLUSTERING AND DIMENSIONALITY REDUCTION OF MULTIVARIATE MIXED-TYPE LONGITUDINAL DATA

Author: Monia Ranalli, Roberto Rocci and Antonello Maruotti

Questions, comments and remarks about the code should be addressed to: Monia Ranalli, email: monia.ranalli at uniroma1.it

In order to reproduce a simulation study one can use files: simula.m.

The main functions are mixhetmixed.m, mixhetmixedN.m and mixhetgaus3.m for fitting HMM with reduction, HMM and HMM for continuous data without reduction, respectively.

The files shall be run in MatLab.
